### **VoxHire**
#### *AI Interview Panel Simulator with Adaptive Follow-Up Questions*
**"Every Answer Changes the Interview."**

[![Repository](https://img.shields.io/badge/GitHub-Repository-0969DA?style=for-the-badge&logo=github&logoColor=white)](https://github.com/devvikax/VoxHire-AI-Interviewer)

</div>

#### Overview
**VoxHire** is an intelligent interview panel simulation platform engineered to transform traditional static assessments into responsive, multi-turn technical dialogues. Rather than reciting scripted questionnaires, VoxHire analyzes candidate explanations in real time, evaluates technical accuracy and architectural depth, updates demonstrated competency states, dynamically scales difficulty, and crafts contextual follow-up inquiries.

```
Candidate Answer ──► AI Understanding ──► Answer Evaluation ──► Skill Update ──► Adaptive Decision ──► Contextual Follow-Up
```

#### Adaptive Interview Intelligence
- **Strong Understanding:** Triggers edge-case scenarios, performance trade-off evaluations, and deeper architectural inquiries.
- **Partial Understanding:** Probes deeper into underlying mechanics, internal components, and lifecycle details.
- **Foundational Gaps:** Prompts clarifying inquiries to evaluate core theoretical comprehension before moving forward.

#### How It Works: Interactive Scenario
> **Candidate:** *"Because Redis is fast."*  
> **VoxHire:** *"What architectural trade-offs make Redis achieve low latency compared to disk-backed stores, and how does in-memory durability affect failure recovery strategies?"*  
*(The simulator dynamically raises complexity when fundamental concepts are stated, driving deeper technical evaluation.)*

#### Key Capabilities
- **Adaptive Question Engine:** Dynamic difficulty re-weighting powered by real-time conversational analysis.
- **Multi-Round Coverage:** Structured Technical Rounds, Live Coding Assessments, and Behavioral/HR evaluations.
- **Diagnostic Final Reports:** Granular assessment matrices highlighting domain strengths, technical accuracy, and improvement paths.
- **Voice-Enabled Interface:** Integrated Speech-to-Text (STT) and Text-to-Speech (TTS) for conversational realism.
- **Multilingual Support:** Conversational interactions in English, Hindi, and Hinglish.
- **Resilient State Architecture:** Deterministic session management and state persistence across interview phases.

#### Project Technology Stack
- **Frontend:** `React` `JavaScript` `Vite` `Tailwind CSS`
- **Backend:** `Node.js` `Express.js` `TypeScript`
- **AI & Evaluation Layer:** `AI Gateway Architecture` `OpenRouter` `Groq` `Adaptive Interview Engine`
- **Data & Sessions:** `Interview State Manager` `Session Management` `Persistent Storage`
- **Voice Processing:** `Speech-to-Text (STT)` `Text-to-Speech (TTS)`
